# 👽 Dex Matchup Oracle

The Matchup Oracle is a really fast and pretty Pokémon type calculator and roster index. 

## 🐸 Features

* **Search Engine:** Instantly search by Pokémon name, specific Typing (e.g., "Water Type"), or Generation (e.g., "Gen 3").
* **Era Conscious:** Type matchups and Pokémon typings change depending on the era. Use the dropdown to switch between Gen 1 Classic, Gen 2-5, and Gen 6+ Modern rules.
* **Interactive Type Badges:** Clicking any type badge in the matchup results instantly pivots the app to a visual database of all Pokémon sharing that type.
* **Zero Dependencies:** 100% Vanilla HTML, CSS, and JavaScript. It's very fast. 

## ❓ How to Use

Since this is a self-contained static app, you don't need any build tools, package managers, or servers.

1.  Clone or download this repository.
2.  Open `index.html` directly in any modern web browser.
3.  *Alternatively:* Visit the live deployment on GitHub Pages (https://spacesame.github.io/matchup-oracle/).

## 🛠️ Tech Stack & Resources

* **Frontend:** Vanilla HTML5, CSS3, ES6 JavaScript
* **Live Data:** Powered by the incredible [PokéAPI](https://pokeapi.co/)
* **Assets:** Type SVGs generously provided by [Duiker101](https://github.com/duiker101/pokemon-type-svg-icons)
